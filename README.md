# Dependency Visualizer

Инструмент командной строки для анализа и визуализации графа зависимостей пакетов Alpine Linux (APK).

Проект разработан в рамках дисциплины «Конфигурационное управление».

## 1. Описание проекта

Программа позволяет получать информацию о зависимостях пакетов Alpine Linux, строить граф зависимостей с учётом транзитивности, обнаруживать циклические зависимости, определять порядок загрузки пакетов и формировать описание графа на языке PlantUML.

Программа написана на Python с использованием стандартной библиотеки. Менеджеры пакетов и сторонние библиотеки для получения зависимостей не используются.

## 2. Реализованная функциональность

### Этап 1. Конфигурация

- Чтение пользовательских параметров из CSV-файла.
- Проверка корректности конфигурации.
- Обработка ошибок при отсутствии или неправильном значении параметров.

### Этап 2. Сбор данных

- Получение индекса пакетов Alpine Linux из удалённого репозитория.
- Чтение архива `APKINDEX.tar.gz`.
- Извлечение сведений о пакетах и их прямых зависимостях.
- Поиск пакета по имени и версии.

### Этап 3. Построение графа

- Построение графа зависимостей алгоритмом BFS с рекурсией.
- Учёт прямых и транзитивных зависимостей.
- Обработка циклических зависимостей.
- Поддержка локальных тестовых репозиториев.

### Этап 4. Дополнительные операции

- Определение порядка загрузки пакетов с помощью топологической сортировки.
- Использование DFS для обработки зависимостей.
- Обнаружение циклов, препятствующих топологической сортировке.

### Этап 5. Визуализация

- Генерация текстового описания графа на языке PlantUML.
- Вывод PlantUML-кода в терминал.
- Сохранение диаграммы в файл `.puml`.
- Поддержка визуализации циклических и ациклических графов.

## 3. Используемые технологии

- Python 3.9+
- CSV
- Alpine Linux APKINDEX
- BFS и DFS
- PlantUML
- Git

Все модули Python входят в стандартную библиотеку.

## 5. Конфигурация

Пользовательские параметры хранятся в CSV-файле.

Пример `config.csv`:

```csv
parameter,value
package_name,git
repository,https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64
test_mode,false
version,2.49.1-r0
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `package_name` | Имя анализируемого пакета |
| `repository` | URL репозитория или путь к тестовому файлу |
| `test_mode` | Режим тестирования (`true` или `false`) |
| `version` | Версия анализируемого пакета |

## 6. Запуск программы

Для запуска необходимо установить Python 3.9 или новее.

В терминале выполнить:

```bash
python main.py config.csv
```

Можно указать другой конфигурационный файл:

```bash
python main.py config_a.csv
```

Если путь не указан, используется `config.csv`.
